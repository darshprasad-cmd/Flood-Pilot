# FloodPilot

**AI Urban Flood Intelligence Platform.**

FloodPilot is not a weather dashboard. It is a decision-making system that predicts
where a city will flood, how deep, and when — then tells a specific person, in a
specific vehicle, on a specific journey, what they should actually do about it.

Every output is explainable. Every prediction carries a confidence score.

---

## Run it locally

```bash
npm install && npm run dev
```

Then open <http://localhost:3000>. Click **Launch App**.

- Landing page — `/`
- Main application — `/app`
- Government dashboard — `/gov` (access-gated)

Demo mode is enabled by default; no API keys are required.
